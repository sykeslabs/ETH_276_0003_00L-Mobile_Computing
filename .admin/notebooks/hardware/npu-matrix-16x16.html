NPU: streamed outputs in matrix C

Values of A move right and values of B move down. The corresponding partial sums appear directly in matrix C as the wave advances. Playback continues across all tiles until matrix C is filled. This illustrates a systolic design, not the internal layout of any particular NPU. A and B are the input matrices; C is their matrix product. The × symbol means multiplication. Each small square represents one matrix entry. A tile is a 4 × 4 block of output entries. A tick is one animation step as input values move between units; it is not a measured hardware clock cycle. Highlighted input squares show the values currently used, while green output squares show completed values.
