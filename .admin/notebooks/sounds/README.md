# Notebook audio

`rocket_landing_applause.wav` is a three-second excerpt of real audience applause from **Applause 2** by **Sandermotions**, recorded at De Doelen theatre in Rotterdam on June 20, 2015.

- Source and license: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:277021_sandermotions_applause-2.wav)
- Original upload: [Freesound, sound 277021](https://freesound.org/people/Sandermotions/sounds/277021/)
- License: [CC0 1.0 Universal (public domain dedication)](https://creativecommons.org/publicdomain/zero/1.0/)
- Adaptation: excerpt from 0.25 to 3.25 seconds, mixed to mono, resampled to 24 kHz / 16-bit PCM WAV, peak adjusted, and faded at both ends.

Notebook `04.3_PID_For_Rocket_Landing.ipynb` embeds this local WAV in its replay output for offline playback after a successful landing. Keep this file with the repository when copying it.
