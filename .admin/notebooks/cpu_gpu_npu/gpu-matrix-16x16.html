GPU: parallel outputs in matrix C

Sixteen partial sums advance together in each tile. Playback continues across all tiles until matrix C is filled. This illustrates parallel tiled multiplication, not the exact execution units or timing of VideoCore VII. A and B are the input matrices; C is their matrix product. The × symbol means multiplication. Each small square represents one matrix entry. A tile is a 4 × 4 block of output entries. The inner index counts the 16 multiplication steps used to build each output. Highlighted input squares show the values currently used; green output squares show completed values.
